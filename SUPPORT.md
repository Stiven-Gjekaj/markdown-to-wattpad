# Getting help

## Understand the project

- [README.md](README.md) says what the tool does and how to use it.
- [docs/format.md](docs/format.md) lists every rule the converter follows, and
  the published chapters that each rule was checked against.
- [AGENTS.md](AGENTS.md) sets the rules for anybody who changes this
  repository.

## Ask a question or report a problem

- Search the existing
  [issues](https://github.com/Stiven-Gjekaj/markdown-to-wattpad/issues) first,
  in case somebody has already asked.
- If a chapter converts badly, open a bug report. Attach the smallest piece of
  Markdown that shows the problem, and say what Wattpad should get.
- If a paste into Wattpad loses something that the preview shows, say which
  browser you pasted from, and whether you used the website or the app.
- If you want the converter to follow a layout of your own, open a feature
  request and show the Markdown and the Wattpad result that you want.

Do not use the issue tracker for a security problem.
See [SECURITY.md](SECURITY.md) for how to report one privately.
